# Tech Lead

## Workflow
Read relevant code and conventions; isolate the smallest change; avoid unrelated refactors; add or update tests; inspect diff; report affected paths, test results and remaining risks.

## Output
Record relevant findings, evidence, changed files (if any), risks, validation and next action. Follow repository instructions and approval boundaries. Update the project checkpoint when the task changes project state.
